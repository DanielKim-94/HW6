How to read this report

Display rounding: experiment and per-document costs use six decimal places; scaled costs per 1,000 documents use four; quoted item prices, monthly costs, and percentages use two. Token counts are whole tokens with comma separators. Scaling uses unrounded values; exact source results and embedded evidence remain unchanged. A scaled 1,000-document cost is a readable normalization, not a new experiment. Monthly estimates refer only to 30,000 documents over 30 days.

Measured means recorded outputs or returned API token counts; dollar amounts apply the supplied prices and are not invoices. Estimate means an extrapolation with stated assumptions. Unknown means not established by this work.

The final defended agent includes document processing, tool-access controls, prompt rules, and an existing local purchasing coordinator. Raw model answers and final pipeline answers are kept separately. These experiments use gpt-6-luna through Portkey; responses report gpt-6-luna-2026-09-22 and an Azure OpenAI route. Metadata is gateway evidence, not independent backend verification. Both email and payment tools are inert logging traps.

Count cached input once

API input tokens already include cached-read and cache-write tokens. For I = input, C = cached reads, W = writes, and O = output, ordinary input is I − C − W.

USD per call = ((I − C − W) × 0.10 + C × 0.01 + W × 0.125 + O × 0.50) / 1,000,000

Rates are USD per million tokens from data/prices.json. Costs sum every returned model call in a selected run. Missing usage is not replaced by zero. Prices exclude unknown gateway fees and do not establish an invoice amount.

For a defended deployment, the measured workloads project to approximately $10.58 with the exam’s warm-cache pattern or $67.73 without cached input. These are distinct workload scenarios, not a confidence interval or a guaranteed cost range.

All projections assume the same model and supplied prices, roughly two calls per document, similar document/output lengths, and the same static handbook and policy. They exclude unknown gateway fees, extra retries, failed attempts, OCR/attachment processing, hosting, local compute, and human review. Cache writes are included at each scenario’s stated frequency. The baseline daily-cold alternative uses (cached batch − startup premium) / 12 × 30,000 + 30 × startup premium, with a $0.001206 USD/prefix-write premium ($1.2065 USD/1,000 such writes) rather than warm read.

The measured explicit cache TTL was 30 minutes. Idle periods, eviction, policy changes, and traffic differences may cause more cold writes. Defended explicit handbook caching was not tested in the same paired design as Problem 4; baseline savings must not be claimed as a measured defended discount. No experiment actually processed 30,000 documents.
